# Zen New Tab

A minimalist start page for the browser's new tab, built with a single HTML file — no frameworks, no build step.

**Live:** https://hanifauliya.github.io/NewTabZenBrowser/

## Features

- Live clock with greeting and a monthly calendar widget
- Search bar with switchable engines (Google, DuckDuckGo, Brave Search); typing a URL opens it directly
- Quick shortcuts to YouTube, Gmail, GitHub, Reddit, Claude, and Gemini
- Quote of the moment
- Transparent background so it blends with the browser's own wallpaper

## Usage

Set `https://hanifauliya.github.io/NewTabZenBrowser/` as the new tab or home page in your browser (for example in Zen Browser or with a "custom new tab" extension), or open `index.html` locally.

## Tech

HTML, CSS, vanilla JavaScript, Font Awesome, Google Fonts (Inter, Playfair Display).
